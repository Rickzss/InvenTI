# InvenTI
Projeto focado na construção de  um sistema de gerenciamento de ativos de tecnológia.

Primeira Etapa 01 (22/10): Realizado a primeira parte do projeto com o CRUD básico (cadastrar usuários novos) e inserido o UPDATE e DELETE dos usuários.
Segunda Etapa 02 (29/10): Tela de login com HTML e CSS (layout, curva e borders), criação de banco de dados (Usuários, Categorias, Setores, Equipamentos, Empréstimos e Histórico).
